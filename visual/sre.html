SRE — how to use this page

Every answer here is computed from the graph. The Cypher query behind a result is always shown, so it can be checked and re-run.

Selecting for Compare

  • Type a name in the left panel, then Add
  • Add to compare in the node details (right panel)
  • Right-click or Shift+click a node in the graph
  • + in search results and in a researcher's publication list

Three Brainstorm modes

  • Compare researchers — 2–3 researchers: shared topics, joint and similar publications, bridge researchers
  • Compare publications — 2–3 publications: shared authors and topics, abstract similarity, up to 5 related publications
  • Summarize this graph — whatever the canvas currently shows

Evidence levels: Direct evidence means a shared topic or a joint publication — not necessarily a past collaboration. Via a bridge means similar publications, a bridge researcher, or an introduction path. Exploratory means the graph holds no evidence; ideas are labelled as such.

Keyboard

  • Enter — search (repeat to step through matches)
  • Esc — close search results or this card
  • Ctrl/Cmd + Enter — run the Cypher query
  • / — jump to the search box

Graph schema

Display names are English; the keys used in Cypher are Indonesian, exactly as stored in the database.

(UnitKerja)-[:MEMILIKI]->(Peneliti)  work unit has member
(UnitKerja)-[:AFILIASI]->(Institusi)  unit is part of institution
(Peneliti)-[:BERAFILIASI]->(Institusi)  external co-authors only
(Peneliti)-[:MENULIS]->(Publikasi)  wrote
(Publikasi)-[:TERBIT_DI]->(Venue)  published in
(Publikasi)-[:MEMBAHAS]->(Topik)  discusses (BERTopic)
(Publikasi)-[:MASUK_KATEGORI]->(Kategori)  ASJC mapping
(Topik)-[:TERMASUK_DALAM]->(Kategori)  topic belongs to category
(Peneliti)-[:BIDANG_KEAHLIAN]->(Topik)  derived expertise
(Peneliti)-[:KOLABORASI]-(Peneliti)  derived: co-authored
(Peneliti)-[:SEBIDANG]-(Peneliti)  derived: similar topic profile

Two category schemes exist: skema:'ASJC' (27 categories) and ASJC-4 (45). A query that walks to categories must pick one, otherwise every row appears twice.
